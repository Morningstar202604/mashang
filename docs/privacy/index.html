隐私政策（Privacy Policy）

生效日期： 2026-10-24

应用名称： 码上（Mashang）

开发者/运营者： bigbad

隐私联系邮箱： bigbad338@outlook.com

（开发者注册地址等工商信息在应用市场开发者后台填写，会随应用公开展示，不在此文件维护。）

一、我们郑重承诺

码上 是一款离线优先的编程学习应用。我们不收集、不上传、不存储任何你的个人信息到任何服务器。你的全部学习数据都只保存在你自己的设备上。本政策依据《中华人民共和国个人信息保护法》《网络安全法》及各应用市场审核规范制定。

二、我们收集的信息

我们不会收集你的任何个人信息。 具体来说：

  • 我们不要求注册账号，也不收集姓名、手机号、邮箱、地理位置等身份信息；
  • 我们不集成任何第三方数据统计、广告或追踪 SDK；
  • 我们不向任何服务器上传你的代码、输入、学习行为或设备信息。

三、设备本地存储的数据

为了提供学习进度功能，以下数据仅保存在你的设备本地（Android DataStore / SharedPreferences），绝不会离开你的设备：

  • 学习进度：已通关课程、练习题通过情况、获得的经验值（XP）与段位；
  • 错题记录：你做错的练习与你的作答（用于本地错题本）；
  • 复习卡：由课程题目生成的间隔复习卡片；
  • 应用偏好：是否首次启动、是否同意本隐私政策、主题选择。

你可以通过以下方式随时清除这些数据：

  • 在「我的」页点击「重置全部进度」清除学习数据；或
  • 直接卸载应用，所有本地数据将随之删除。

四、网络权限说明

应用声明了 INTERNET（联网）权限，仅在以下两种你主动触发的场景使用：

1. 内容中心：手动检查 / 下载课程拓展包。请求只包含课程包文件名，不携带任何个人信息；下载内容做 SHA-256 完整性校验。

2. 检查更新：手动点击后读取 GitHub Releases 的公开版本号（不发送设备标识、不上传学习数据、不自动下载安装包）。

除上述主动操作外，应用在无网络环境下可完整运行全部内置课程。

五、网页版

网页版（https://badhope.github.io/mashang/web/）与 App 使用同一套课程内容：

  • 学习进度仅保存在浏览器 `localStorage`，不上传服务器；
  • 首次加载需从公共 CDN（jsDelivr / unpkg）下载 Pyodide 运行时（约 12 MB），该请求由 CDN 按其自身隐私政策处理访问日志；
  • 我们不在网页版使用 Cookie、统计脚本或广告。

六、关于嵌入的语言运行时

应用通过 Chaquopy 在设备端嵌入真实的 CPython 解释器，并通过 Rhino 提供 JavaScript 运行时。所有代码均在你的手机本地执行，不会发送到任何外部服务器。

七、未成年人保护

本应用面向全年龄段，内容为编程学习，不含任何面向未成年人的定向收集或商业推送。我们建议未成年人在监护人指导下使用。

八、你的权利

你有权了解、更正、删除你的本地数据（见第三节）。由于我们不持有任何服务器端个人信息，无需额外的数据导出或注销账户流程。

九、本政策的变更

如本政策发生变更，我们将在应用内「关于」页与项目仓库中更新，并在必要时重新征求你的同意。

十、联系我们

如你对隐私事宜有任何疑问，请联系：bigbad338@outlook.com
