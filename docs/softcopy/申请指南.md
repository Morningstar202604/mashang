# 码上 · 软件著作权登记申请指南

面向本项目（码上多语言编程学习软件）的软著登记实操手册。
办理入口：中国版权保护中心 <https://www.ccopyright.com.cn>（著作权登记系统在线填报）。

> **本文档为办理流程与材料填写指引，不构成法律意见。** 涉及权利归属、合作开发、职务作品的认定，请以官方要求或执业律师意见为准。

---

## 1 登记的价值与边界

### 1.1 能拿到什么

- **《计算机软件著作权登记证书》**：证明软件的开发者、开发完成日期、首次发表日期与权利归属
- 实际用途：APP 上架部分应用市场要求、企业/个人技术成果认定、高新技术企业申报、职务晋升与项目结题佐证

### 1.2 不能拿到什么（常见误解）

| 误解 | 事实 |
| --- | --- |
| 软著保护"创意/玩法" | 软著只保护**代码与文档的表达形式**，不保护算法思想、商业模式、交互创意 |
| 拿到软著就能阻止别人做同类产品 | 他人独立编写的代码不构成侵权；软著登记**不做实质审查**，不具备排他效力 |
| 软著等于商标 | 两回事。品牌名（"码上"）需要另行申请**商标**才有排他保护 |
| 开源了就不能登记软著 | **可以登记**。著作权自代码完成时自动产生，开源许可是权利的行使方式，不影响权属 |

## 2 办理流程

```
① 准备材料（源程序册 + 文档册 + 身份证明）
        ↓
② 中国版权保护中心网站注册实名账号 → 实名认证（1–3 个工作日）
        ↓
③ 在线填报申请表 → 上传源程序 PDF、文档 PDF、身份证明
        ↓
④ 提交 → 受理（约 1 个月左右出受理通知）
        ↓
⑤ 审查 → 补正（如有）→ 核准
        ↓
⑥ 领取登记证书（电子证书可自行下载）
```

- **普通办理**：免费，周期约 30–60 个工作日（各地与时段波动较大）
- **加急办理**：需通过代理机构付费加急，可缩短至数个工作日

## 5 源程序册：已自动生成

### 5.1 生成方式

```bash
python tools/softcopy_source.py
# 可选参数：
#   --name    "码上多语言编程学习软件"   （页眉软件名）
#   --version "V1.0"                    （页眉版本号）
#   --out     dist/softcopy
```

输出：

| 文件 | 用途 |
| --- | --- |
| `源程序.html` | 浏览器打开 → Ctrl+P → 另存为 PDF，即送审件 |
| `源程序.txt` | 纯文本备份，页间以分页符分隔 |
| `源程序清单.csv` | 每份文件的行数与入选页码区间，便于自查补件 |

### 5.2 格式合规性

| 受理要求 | 本册实现 |
| --- | --- |
| 前后各连续 30 页，共 60 页 | 总 199 页 → 取前 30 页 + 后 30 页 ✅ |
| 每页不少于 50 行 | 每页固定 50 行（末页不足 50 行以空行补齐）✅ |
| 页眉标注软件名称 + 版本号 | 每页页眉「码上多语言编程学习软件 V1.0」✅ |
| 标注页码 | 每页右下角「当前页 / 60」✅ |

### 5.3 打印设置

用 Chrome / Edge 打开 `源程序.html`，Ctrl+P：

- 目标：**另存为 PDF**
- 纸张：**A4**
- 边距：**默认**（样式已内置页边距，选默认即可）
- 缩放：**默认（100%）**
- 背景图形：**关闭**（关掉更省墨，且不影响文字）

### 5.4 重要提醒

> **只收录原创代码。** 脚本已自动排除构建产物、测试目录与第三方依赖，仅收录 `app/src/main/java` 与 `app/src/main/python` 下的 57 个原创源文件。切勿把 `build/` 目录、Gradle 依赖源码或 sora-editor 源码混入——一旦被认定为非原创，会被要求补正甚至驳回。

## 7 必须处理的前置事项

### 7.1 ⚠️ 申请人主体不能用团队名

`LICENSE` 与 `AppConstants.DEV_NAME` 现在是 `码上 (Mashang) Team` / `bigbad`。
**软著申请人必须是身份证上的真实姓名（自然人）或工商登记的企业名称。** 请确认权属落到具体主体，并在申请表中如实填写。

### 7.2 ⚠️ 软件名称需查重

提交前先到版权保护中心查询是否有同名或近似软件登记。若系统提示重名，会被要求改名。备选名称：

- 码上多语言编程学习软件（首选）
- 码上编程学习系统
- 码上离线编程学习软件

### 7.3 ⚠️ 「码上」商标需单独申请

软著不保护品牌名。若打算长期运营"码上"品牌，**另需向国家知识产权局商标局申请第 9 类（可下载软件）/ 第 41 类（教育培训）商标**。建议在提交软著的同时启动商标检索，避免日后被迫改名。

### 7.4 ⚠️ 第三方许可合规

| 组件 | 许可 | 登记时的处理 |
| --- | --- | --- |
| sora-editor / language-textmate | **LGPL-2.1** | 以依赖方式引入、不进源程序册；若要分发 APK，需遵守 LGPL 的"可替换该库"要求并保留许可声明 |
| Chaquopy | 其自有许可 | 免费版通常有限制，商用前务必核对许可条款 |
| AndroidX / Jetpack / ZXing | Apache-2.0 | 保留许可声明即可 |
| Pyodide（网页端） | MPL-2.0 | 网页端非本次登记范围 |

> 软著登记**不做实质审查**，因此不会主动核查第三方许可；但这不代表没有合规义务。若后续商业化，需自行完成开源许可合规审查。

## 8 常见补正原因（提交前自查）

| 补正原因 | 自查方法 |
| --- | --- |
| 源程序每页不足 50 行 | 检查打印缩放，确认未被缩小 |
| 页眉缺少软件名或版本号 | 检查打印时是否勾选了"页眉页脚"（应关闭，样式已内置页眉） |
| 前后 30 页重复或顺序错乱 | 确认源程序册由脚本生成且文件顺序固定 |
| 源程序混入第三方代码 | 用 `源程序清单.csv` 核对，应全部为 `app/src/main/` 下的原创文件 |
| 软件名称不以"软件/系统/平台"结尾 | 使用第 4.1 节的名称 |
| 申请人名称与证件不一致 | 申请人填身份证姓名，不要填网名或团队名 |
| 文档页数不足或格式不符 | 文档册不足 60 页时全部提交即可 |
